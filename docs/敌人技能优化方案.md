# 敌人技能优化方案（小怪 / 小 Boss / ch1~ch4 大 Boss）

> 2026-11-09 起草，同日实施 P1~P3（见文末实施记录）。目标：解决「小怪、小 Boss、初始几个大 Boss 技能太过单一」。
> 方案分四层：通用走位层 → 小怪层 → 小 Boss 层 → 大 Boss 层，另附支撑系统、数值约定与分期落地计划。
> 所有设计遵守现有代码铁律：技能必须带前摇预警、判定体积（radius）不动、数值走既有乘区、美术只复用现有资源。

---

## 一、现状诊断

### 1.1 大 Boss（ch1~ch4，问题最重）

`BossController._useSkill()`（BossController.ts:476）里 ch1~ch4 各只有 **1 个专属弹幕**：

| Boss | 专属技能 | 通用技能 | 阶段变化 |
|---|---|---|---|
| ch1 废土领主·腐肉 | 3 发毒球 | 召唤 3 只 grunt + 通用冲锋 | 仅 +20% 移速 |
| ch2 钢铁之王·熔炉 | 8 向齿轮弹 | 同上 | 同上 |
| ch3 海克斯异变体 | 1 发追踪弹 | 同上 | 同上 |
| ch4 混沌深渊 | 12 发随机弹 | 同上 | 同上 |

四个 Boss 本质是**同一个模板换弹型**。而 ch5 机械高达（横劈/剑气/光剑/坠击+被动格挡共 5 招）、ch6 灭世机神（网格激光/集束导弹/追踪弹/最终形态）、三只文档 Boss（维斯帕/坩埚/万相各 5 招固定轮转）都已有成熟结构——**ch1~ch4 是唯一的洼地**，应直接套用 doc boss 的「阶段解锁 + 固定轮转」调度器。

### 1.2 小怪（旧 7 种）

旧 7 种中 5 种（grunt / shield / exploder / golem / elite_grunt / miniboss 暗影猎手）共享**同一行为模板：直线追击 → 前摇 → 单体近战**；archer 是唯一的拉扯射手；exploder 只有死亡爆炸。**暗影猎手名义是小 Boss（800 血），实际零技能**，纯数值怪。对比新 9 种 TEST_GRUNTS（扑击、三连校射、火圈、冰三连、毒圈、锁向冲锋、连线增益、逃逸、可引爆自爆）已有完整机制层。

另一根本问题在**移动 AI**：所有近战的移动向量都是「指向玩家」归一化（EnemyBase.update() L1096），多只怪挤成一条直线纵队，玩家只需沿垂直方向走即可无伤——这是「感觉单一」的最大来源，比缺技能更伤体验。

### 1.3 小 Boss（旧 6 只 vs 新 5 只）

- 旧 6 只（squid/turtle/shrimp/jelly/drone_a/drone_s）：2~3 招且多为「发一发弹就完」，无血线变化；
- 新 5 只（chain_hound/prism_snail/triune_priest/rail_butcher/bell_devourer）：复合机制（扫描线、拖拽、轨迹回放、可反制护盾）+ 严格互斥调度，质量已达标；
- **squid 有遗留 bug 级体验问题**：`_miniBossSquid()` 放完 3 个技能就自毁（EnemyBase.ts:1887），这是它作为「深海恐惧水柱召唤物」的一次性设定，但 squid 现已进入图 2/3/4 的正式 `miniPool`（史诗档），W5 试炼波里它会在约 12 秒后自杀送掉。

## 二、设计原则（全部技能的验收标准）

1. **可读性优先**：每个新技能 = 技能名浮字 + 前摇预警（圈/线/带/变色）+ `enemySignature` 粒子，三者齐备才准结算伤害。参照现有 `attackWindup` / `miniSkillState` / `telegraphZones` 体系。
2. **技能数配平**：小怪 ≥1 个改变威胁形状的主动机制；小 Boss 普通 3 招 / 史诗 4 招 / 地狱 4 招+阶段强化；大 Boss 5 招（普攻 + 4 技能含 1 终技）。
3. **阶段感**：大 Boss P1 只出前 2 招、P2 出 4 招、P3 先强制终技再全轮转（与 `_updateDocBossSkills` 完全一致）；小 Boss 统一在 50% 血进入「激怒」（技能 CD ×0.85，部分解锁新行为）。
4. **复用基础设施**：新技能尽量由现有件拼装——弹体 flag（`homing/bounceLeft/dot/slow/pierceShield/explodeOnExpire`）、地面危险区（`spawnEnemyAcidHazard/spawnEnemyEmberHazard/telegraphZones`）、微型冲锋通道（`_chargeT`）、正面减伤（`combatFacing/frontGuardBroken`）、玩家 debuff（`player.applyBuff` 的 noMove/silence/stun）。
5. **数值纪律**：Boss 技能伤害一律写 `damage × 百分比`（沿用现有 0.4~0.8 区间），自动吃难度乘区与 `bossSkillCut` 简单难度削减；`radius` 永不改，视觉放大只走 `visualScale`。
6. **零新增美术**：全部复用现有弹型（`enemyFx`）与贴图；确需新特效时先登记 `docs/art/art-needs.md`，不阻塞本方案。

## 三、小怪层方案

### 3.1 通用：侧移包抄（flanking）——本层最高优先级

给 `EnemyBase` 增加走位偏置，解决「一条直线纵队」：

- `init()` 时按类型分配 `flankBias`（Rng 三取一：-1 / 0 / 1），近战默认全员参与；
- 移动向量合成处（update() 计算 `[dx,dy]` 之后）：与玩家距离 > 220px 时，把指向向量旋转 `±28° × flankBias`（异侧怪自动形成钳形）；距离 ≤ 220px 回正为直指，保证贴身命中手感不变；
- 只作用于移动向量，不影响仇恨目标选择（`tideConverge` / 保命分身 / 骸骨军团优先级全保留）、不影响 `attackWindup` 锁定。

验收：测试房放 8 只 grunt，应呈两翼包抄弧线而非纵队；`tests/dist` 增加向量合成用例。

### 3.2 旧 7 种逐个设计（每只一个「记住它」的机制）

| 小怪 | 新机制 | 实现要点 | 优先级 |
|---|---|---|---|
| grunt 腐尸 | **扑咬冲刺**：距玩家 120~220px 时 0.3s 前摇（复用 attackWindup 危险圈）→ 沿锁定方向冲 180px | 复用 `_chargeT` 通道与 rust_biter 分支的写法（EnemyBase.ts:984） | P1 |
| grunt 腐尸（被动） | **尸潮狂暴**：半径 150px 内每死 3 只同类，攻速 +25%、移速 +15%（上限 2 层，浮字「狂暴」） | update() 里数 `game.enemies` 死亡事件可由 GameManager 维护计数 | P2 |
| shield 护盾兵 | **举盾姿态**：每 6s 举盾 3s，正面 120° 减伤 70%（复用 rivet_beast 的 `combatFacing` 点积判定），举盾期移速 -30%；能量盾被打破时眩晕 1s | 判定代码抄 rivet_beast takeDamage 分支（EnemyBase.ts:476） | P1 |
| exploder 爆炸怪 | **酸液腐爆**：死亡爆炸保留，爆炸位置留 3s 酸池（复用 `spawnEnemyAcidHazard`，伤害减半档） | 与熔爆蜱（纯爆伤、可提前引爆）形成差异分工 | P2 |
| golem 石像鬼 | **蓄力震地**：近战攻击从单体改为落点圆形 AoE（半径 90），前摇沿用 0.56s，落点画圈；命中附带 0.6s 减速 | 前摇危险圈渲染层已支持（attackWindup>0 时绘制） | P1 |
| elite_grunt 精英 | **猎杀突进**：8s CD，锁定玩家位置冲锋 280px（伤 1.2×，命中击退 40px） | 复用 `_chargeT`；精英波（W4/W8/W14）威胁形状质变 | P1 |
| archer 毒射手 | **腐蚀箭雨**：每第 4 发毒镖改为落点毒圈（0.8s 预警，复用 acid_sac 的 `spawnEnemyAcidHazard`） | 计数器 `_shotsFired`，迫使玩家不能永远站桩输出 | P2 |
| miniboss 暗影猎手 | **影袭**：8s CD，消失 0.5s（落点侧方闪烁提示）→ 玩家背后 80px 现身 → 0.4s 前摇爪击 2× 伤害；血量 < 40% 后每 15s 受击时放烟雾隐身 1s | 它是图 4/5/6 高级近战池主力，从纯数值怪变成真正的刺客 | P1 |

### 3.3 数值锚点

新机制伤害全部取 `self.damage` 系数（0.5~1.2×），前摇 0.3~0.85s 与现有 TEST_GRUNTS 同档；金币/掉落不动。

## 四、小 Boss 层方案

### 4.1 档位标准与统一机制

- 技能数补齐：普通 ≥3、史诗 ≥4、地狱 ≥4；
- **激怒（血线 50%）**：全小 Boss 统一——技能 CD ×0.85、浮字「激怒！」、`glowColor` 呼吸提亮（渲染层读一个 `enraged` 标记即可）。bell_devourer 现有 45% 解锁吞音反震改挂到同一血线判断里。

### 4.2 旧 6 只补招设计

| 小 Boss | 现有 | 新增（补齐至档位） |
|---|---|---|
| turtle 盾龟（普通） | 被动盾、高速碰撞 | **裂地波**：冲锋结束/撞墙瞬间脚下发 8 向环形地刺弹（速度 175，伤 0.5×，复用棱壳闭壳弹型） |
| jelly 毒刺鬼水母（普通） | 隐身循环、毒刺 | **麻痹触须**：贴身 60px 触发缠绕 0.8s（复用 `squid_grab` 的 noMove buff）；隐身期间移速 +40%（隐身从「白给无敌」变成进攻窗口，玩家可预判现形点） |
| drone_a 攻击无人机（普通） | 声波、锁定光束 | **过载机动**：每 7s 三段侧闪（每段 0.12s 朝玩家侧后方 120° 位移 140px），每段后立即补一发声波弹——从站桩射手变成走位射手 |
| squid 深海鱿鱼（史诗） | 缠绕、深水炸弹、分裂水刺（+自毁） | **修正自毁**：自毁仅保留给「深海恐惧水柱召唤物」（GameManager `abyssSummonSquid` 生成时打 `_oneShot=true` 标记），正式波次不自毁、技能循环；**墨烟遁**：血量首次 < 50% 释放半径 120 减速烟雾（0.6× 减速 2s）+ 向后瞬移 260px |

### 4.3 新 5 只微调

机制已达标，只接入统一「激怒」血线（CD ×0.85），其余不动，避免返工已验收内容。

## 五、大 Boss（ch1~ch4）技能重做 —— 方案主体

### 5.1 架构：套用 doc boss 调度器

把 ch1~ch4 从 `_useSkill()` 的单技能 switch 迁移到与 `_updateDocBossSkills`（BossController.ts:428）同构的**固定轮转状态机**：

```
普攻（docBasicTimer，1.55~2.1s 节奏，保留现有弹型）
+ 技能轮转（7.8s 间隔，P3 ×0.85）：
    P1 池 [0,1] → P2 池 [0,1,2,3] → P3 先强制终技[4]再全池轮转
```

- `bossSkillCut`（简单难度 1/3 削减）沿用 `pool = [0]` 的既有逻辑，自动生效；
- 测试房 `boss_ch1~4` 卡天然获得全技能集，沿用逐项验收流程；
- 技能实现集中到新文件 `entities/BossChapterSkills.ts`（纯函数库，签名 `(boss, player, game) => void`），BossController 只保留调度，不再膨胀；
- 新技能需要的 2 个预警渲染件（见 6.1）由 GameManager 提供。

## 六、支撑系统（新增/复用清单）

### 6.1 GameManager 新增 2 个通用预警渲染件

现有：圆圈（`telegraphZones`）、网格带（`_invGrid`）、危险圈（attackWindup）。需补：

1. **线预警** `spawnLineTelegraph(x, y, angle, length, duration)`：磁轨狙击 / 后续所有直线弹用；
2. **带状预警** `spawnLaneTelegraph(horizontal, index, duration)`：熔毁带用，可从 `_invGrid` 的渲染分支抽公共件。

两者同样服务未来所有敌人技能，一次投入全局收益。

### 6.2 弹体新 flag（BulletController）

- `attract?: { radius: number, pullSpeed: number }`：奇点用，主循环里对玩家施加向心位移、对 `owner==='player'` 子弹做半径内吸收计数（存回弹体 `absorbedCount`）。

### 6.3 实体层新通道

- `EnemyBase.flankBias`（侧移包抄，3.1）；
- `EnemyBase._oneShot`（squid 一次性标记，4.2）；
- `EnemyBase.enragedAtHalf`（小 Boss 统一激怒，血线判断放 `_updateMiniBoss` 入口）；
- `BossController` 新增 `_updateChapterBossSkills()` + `docSkillName` 机制复用（技能名浮字走现有字段）。

### 6.4 数据表变更

## 七、平衡与验收

- **伤害区间**：大 Boss 技能 0.4~0.8× damage（与现有 ch1~ch6 弹幕一致）；召唤物沿用各自表值，不吃 Boss 系数（防止滚雪球）。
- **节奏**：大 Boss 主技间隔 7.8s（doc boss 同款）、普攻 1.55~2.1s；小 Boss 技能 CD 4~12s 保持现有档差。
- **难度自动适配**：`_applyDifficulty` 乘区、`bossSkillCut`、变异（`time_crack` 攻速等）对新技能全部自动生效，不需要逐技能适配。
- **验收流程**：每期完成后 `npm test` + `npm run typecheck`，测试房逐项过一遍新技能（前摇可见、可躲避、浮字正确），停在待提交状态等用户确认。
