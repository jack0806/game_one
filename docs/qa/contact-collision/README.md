# 近身阻挡与滑动验收（2026-10-10）

普通走路在双方身体接触前截断向内位移，保留切向位移。英雄走向敌人时停止或沿边缘滑动；敌人追近时同样停止，不通过推走对方修补正常走路的重叠。近身后排尝试侧绕前排，首领停步距离与近战前摇触发距离保持一致。

技能冲锋、击退、英雄闪避沿用各自规则。出生、落地、瞬移等已经重叠的异常状态仍由原身体分离逻辑兜底。敌人之间的占位与侧绕仅在距英雄 260 像素内启用。

## 复现

先使用 `tools/build-web-desktop.json` 完成 Cocos 构建，再运行 `python -B tools/serve_enemy_review.py`，打开 `http://127.0.0.1:8317/collision-review`。点击“全量碰撞验收”或“观看近身与绕行”。验收页使用真实游戏控制器及主循环，移除随机场景障碍以固定单位接触场景；地形覆盖由回归测试提供。

`collision-blocked.png` 为持续向首领直走后的画面，`collision-slide.png` 为继续斜向绕行后的画面，`collision-crowd.png` 为后排绕开前排后的画面。其余单位截图记录各自的接触状态。
