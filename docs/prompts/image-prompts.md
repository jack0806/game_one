## 通用说明（先读）

1. **透明背景**：即梦一般不直接输出透明 PNG。凡标注"需透明"的图，提示词里已写"纯黑色背景"——生成后抠图（推荐 remove.bg / Photoshop"移除黑色背景"模式）导出带 Alpha 的 PNG 再覆盖原文件。特效、角色、敌人、子弹、头像、图标都需要透明；背景图与标题屏不需要。
2. **风格锚定**：全游戏统一风格 = "海克斯科技幻想"（Hex-tech，类似《英雄联盟：双城之战》的霓虹科技+魔法质感）。每组提示词开头都带同一风格锚定句，建议**同组图同一批次生成**（相同种子/参考图），保证风格一致。
3. **参考图**：即梦支持上传参考图。重生成某张图时，可先上传现有的对应旧图作为风格参考，再用提示词调整细节，一致性最好。
4. **尺寸**：即梦按比例出图（16:9 / 1:1 / 3:4 / 9:16 等），文档中给出比例要求，出图分辨率选最高档，无需精确到像素（引擎按 CUSTOM 模式缩放显示）。
