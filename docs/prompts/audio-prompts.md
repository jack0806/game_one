# 即梦音乐 / 音效生成提示词全集（7 BGM + 17 SFX）

> 配套任务清单与代码接线步骤见 `docs/audio/audio-needs.md`（先做 AudioManager 代码层，资源才有地方播）。
> 音频是**全新资源**：放到 `assets/resources/audio/bgm/` 与 `assets/resources/audio/sfx/`，文件名按本文档"保存名"。目前仓库里没有任何音频。

## 通用说明（先读）

1. **BGM 用即梦"音乐生成"**：选纯音乐/无人声模式，把提示词粘贴进"风格描述/自定义歌词"输入框（歌词留空）。生成后挑选首尾衔接平缓的版本；如有条件用音频软件做 2 秈交叉淡化转成无缝循环。
2. **SFX 用短音频生成**：即梦音乐偏长段落，生成 SFX 时在提示词里强调"极短、一声"；生成后用音频软件裁出 0.2–1.5s 有效段。若即梦短音效效果不理想，可改用免费音效库（如 freesound）找同描述素材，但风格要贴海克斯科技感。
3. **统一音量**：所有素材入库前统一响度（BGM 约 -20 LUFS，SFX 约 -16 LUFS），避免游戏中忽大忽小。
4. 格式统一 mp3（Cocos 3.8 支持 mp3/ogg/wav；mp3 体积最小）。采样率 44100Hz。
