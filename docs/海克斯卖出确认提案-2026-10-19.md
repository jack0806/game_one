# 海克斯卖出确认提案（2026-10-19）

> 状态：**待确认**（文档先行，未动代码）。
> 目标：海克斯强化**不能"点一下就卖掉"**——每个持有海克斯显示一个显式的「卖出」按钮，点击后弹出**确认弹窗**，点「确认卖出」才真正执行。
> 范围：仅波间海克斯商店（`AugSelectUI`）。大厅装备仓库卖出、补给商店不在本次范围（如需同样加确认，另行小提案）。

## 1. 现状与问题

持有海克斯在商店底部标签区展示（10 格/页，可翻页）。当前交互是**两步点击确认**：首点标签进入确认态（红边 + 文案变「再点一次确认卖出」），再点同一标签才卖出（`_sellPendingIdx/_sellPendingId`，AugSelectUI.ts:550）。

| 问题 | 明细 |
|---|---|
| ① 热区=整个标签 | 卖出热区覆盖整条 188×44 标签，玩家想点开看、或习惯性快速连点时**双击即卖**，红边确认态停留时间太短拦不住 |
| ② 无显式入口 | 「卖出」没有按钮，只能靠提示文字"点击持有标签两次确认卖出"来教，可发现性差 |
| ③ 确认反馈弱 | 确认态只是描边变红，没有金额与后果的确认弹窗；误卖高购价海克斯（彩色卡实付数百金币）只能回收 75%，损失真实 |

## 2. 新交互设计

### 2.1 持有标签改造

```
┌────────────────────────────────────────────┐
│  [功] 狂暴基因 Lv2            ┌──────────┐  │   188×44 标签
│  （名称区，点击不再触发卖出）   │ 卖 34    │  │   ← 右缘内嵌卖出按钮 ≈52×36
└──────────────────────────────┴──────────┘  │
```

- **标签本体**：只展示 `[功] 名称 LvN`（稀有度描边色保留），**点击不再触发任何行为**（删除 chip 整体 TOUCH_END → _sell 的绑定）。
- **卖出按钮**：内嵌标签右缘，红色系装甲皮（`applyHexButtonSkin`），文案 **`卖 N`**——N = 回收金额（`round(paid × 0.75)`，与当前展示口径一致），玩家不点开就知道能卖多少。
- 键盘焦点从标签移到卖出按钮上（`registerKeyboardFocus`），Tab 顺序=标签顺序。

### 2.2 确认弹窗

点「卖 N」→ 弹出**模态确认弹窗**（面板内构建一次、随用随显，居中 ≈560×300，`drawHexPanel` 装甲底 + 不透明遮罩）：

```
        确认卖出
   ────────────────────────
   狂暴基因  Lv.2            （名称吃稀有度色）
   回收  34 金币（购价的 75%）
   卖出后立即从技能格移除，本局内如需再用须重新购入
   ────────────────────────
   [ 取消 ]        [ 确认卖出 ]   （确认键红色系）
```

- 弹窗打开期间 `BlockInputEvents` 拦截一切穿透：底部标签、翻页、刷新、继续战斗都点不到。
- 键盘：弹窗根节点 `registerKeyboardModalScope`（同英雄介绍弹窗二级层的做法），Tab 在「取消/确认卖出」间循环，Enter 激活。
- 「确认卖出」→ 调 `ctx.sell()` → 关弹窗 → `_populate()` 刷新金币与标签；「取消」/点遮罩 → 仅关弹窗。

### 2.3 状态与生命周期清理

- 删除 `_sellPendingIdx` / `_sellPendingId` 两步确认状态与「再点一次确认卖出」文案。
- 弹窗引用 `_sellPendingId`（改为 `_confirmId`）语义保留：打开时记录目标 id，确认时校验仍持有（防极端时序）。
- `show()` / 翻页（`_changeChipPage`）时若弹窗开着先关闭；`hide()` 一并关闭。

### 2.4 文案更新

底部提示行（AugSelectUI.ts:331）改为：
`点击「卖出」并确认后回收 75% 购价 · 功能海克斯不占技能格`

## 3. 边界情况

| 情况 | 处理 |
|---|---|
| 弹窗开着时波间流程推进 | 不可能：弹窗模态拦截「继续战斗」，必须先取消或确认 |
| 确认瞬间该海克斯已被移除（防御） | `ctx.sell()` 返回 false 不刷新金额，弹窗关闭并 `_populate()` 校正 |
| 功能海克斯多个同类实例 | 卖出语义不变（`sell({id})` 按现有逻辑移除一个实例），弹窗照常确认 |
| 触屏 | 同一交互，无 hover 依赖；按钮 52×36 满足触控最小尺寸 |
| 固定（pin）/刷新 | 不受影响：卖出只作用于已持有标签区 |
