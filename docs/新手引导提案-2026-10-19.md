# 新手引导提案（2026-10-19）

> 状态：**已实现（2026-10-19），按玩家同日指示改版**——引导不放首页、不放设置页查看入口，改为**正式游戏内进行**：第 1 章首战开打前弹出 4 页图文卡（压住首波），关闭后开战并进入战斗内浮字提示段（移动 → 技能，达成即收起）；设置页改放「新手引导：开/关」**开关**（设备级持久化，缺省开），关闭后不再播放；播放与否只看"开关开 + 本设备未播过"，不再区分新老玩家。下文第 2 节的"首页自动弹出/设置页重看/老玩家跳过"为初版方案，已被上述改版取代，4 页文案与模块拆分仍然有效。
> 目标：玩家**第一次进入游戏**（首页标题画面出现后）自动弹出一段**可跳过的图文引导**，讲清四件事：这是什么游戏、从大厅到战场怎么走、键鼠/触屏怎么操作、战斗循环是什么样。
> 形式：全屏浮层分页卡片（4 页），完成或跳过后写入设备级标记不再弹出；设置页新增「新手引导」按钮可随时重看。
> 关联：入口流程见《关卡设计-六图五章.md》；设置页结构见《后台管理系统提案-2026-10-13.md》。

## 1. 定位与边界

- **教什么**：只教"上手必需"的四块认知（游戏类型 / 流程 / 操作 / 战斗循环），不剧透怪物机制、变异、难度细节——这些留给玩家在游玩中发现。
- **不做什么**：本次不做战斗内逐步引导（限速、按键锁定、区域高亮那类重引导），列为可选二期（第 8 节）。理由：进战斗前的长流程（首页→选档→大厅→选图/章/难度/英雄）每一步页面自带说明文字，缺口主要在"全局认知"；而战斗内的浮字提示（二期）成本低得多，先验证玩家是否真的卡在操作上。
- **不新增美术资源**：面板全部用现有 `UIStyle`（`drawHexPanel` / 按钮皮肤 / `UI_PALETTE`）+ `Label` 纯代码绘制，不引用新 PNG，不触碰 `assets/resources/art/`。

## 2. 触发时机与「第一次」判定

> 首次引导发生在**选存档槽之前**（首页画面），所以标记必须是**设备/浏览器级**的全局 key，不能放进 `PlayerProfile`（那是槽位级的）。与后台管理（`hexblast_admin_*`）同级处理。

- 存储：`sys.localStorage`，key `hexblast_tutorial_v1`，值 `'done'`。
- 弹出时机：`GameManager.onLoad` 末尾（`_setState('menu')` 之后）判定，命中则延迟约 0.4s 调 `ScreenManager.show('tutorial')`——避开启动加载闪屏，让标题画面先立住。

| 场景 | 引导标记 | 任意槽位有存档（含 legacy key） | 行为 |
|---|---|---|---|
| 新玩家 | 无 | 无 | **自动弹出**引导 |
| 老玩家升级到新版本 | 无 | 有 | **不弹**（静默补写标记），设置页可重看 |
| 已看过/跳过 | 有 | 任意 | 不弹 |

> 老玩家跳过的理由：版本更新后强弹 4 页图文对老玩家是打扰；他们真需要时设置页一点就有。legacy key（`hexblast_profile_v1`，`SaveSystem.LEGACY_KEY`）一并视为"有存档"。

**重看入口**：设置页（`ScreenManager._buildSettingsPanel`）新增「新手引导」按钮 → 打开引导浮层；关闭后**回到设置页**（GameManager 记录发起来源）。首次自动弹出的场景关闭后停在首页。

## 3. 引导内容（4 页文案草稿）

> 每页 = 眉题（小字拼音频）+ 标题 + 正文。正文文案以下是草稿，实现时可再润色；**涉及后台可调数值的地方刻意写模糊**（如折算比例不写死 20%），避免后台改参数后文案失真。

### 页 1 · 欢迎（是什么游戏）

- 眉题：`WELCOME / 欢迎入驻`
- 标题：欢迎来到 HEXBLAST
- 正文：这是一款**顶视角射击 Roguelite**——带领英雄突入废土战区，一局一个章节、15 波敌潮。击杀敌人拾取金币与装备，波间歇息时用海克斯强化把火力滚成雪球。
- 页脚小字：约 30 秒的快速说明，随时可点「跳过」。

### 页 2 · 冒险流程（怎么走）

- 眉题：`CAMPAIGN / 出击流程`
- 标题：从大厅到战场
- 正文（编号列表）：
  1. 首页点「开始游戏」，选择一个档案槽（3 个存档相互独立）；
  2. **存档大厅**是你的基地：传送门出击、图鉴与成就墙、装备仓库（装备跨局永久保留，不需要的可卖出换金币）；
  3. 经传送门依次**选战区地图 → 选章节 → 定难度 → 挑英雄**，即可开战；
  4. 一局打完一个章节（15 波）；通关当前战区才能解锁下一张地图。

### 页 3 · 操作（怎么打，按平台二选一渲染）

- 眉题：`CONTROLS / 战地手册`
- 标题：移动 · 瞄准 · 技能

**PC（键鼠）版：**

| 按键 | 作用 |
|---|---|
| `W A S D` / 方向键 | 移动 |
| 鼠标 | 瞄准——**普攻自动发射**，你只管走位和转火 |
| `Q` `E` `R` | 英雄技能（右下角图标看冷却） |
| `Esc` / `M` | 暂停 / 属性面板 |

**触屏版：**

| 部位 | 作用 |
|---|---|
| 左下角摇杆 | 移动（手指按在左半屏任意处可重新锚定） |
| —— | 普攻自动发射，专心走位躲弹幕 |
| 右下角 Q / E / R 按钮 | 英雄技能（带冷却进度环） |
| 右上角按钮 | 暂停 / 属性 |

### 页 4 · 战斗循环（怎么赢）

- 眉题：`COMBAT LOOP / 波次循环`
- 标题：一波一波，滚成雪球
- 正文（编号列表）：
  1. 清空一波敌人 → 弹出**海克斯三选一**，挑一张强化自己（首波免费送三张功能性强化）；
  2. 部分波次清空后还会进入**关中商店**，用金币买属性、补状态；
  3. 每章第 15 波是**章节关底**——击败它即通关；
  4. 通关结算：剩余金币折算成**核心币**（元进度货币），并解锁下一段战线。
- 结尾一句（强调色）：祝首战顺利，指挥官！

**按钮与页脚**：左下「跳过引导」；右下「上一步 / 下一步」，末页下一步变「开始行动」；底部中央圆点进度指示（当前页高亮）。

## 4. 交互与视觉设计

- **层级**：全屏遮罩（`Color(4,6,12,170)`，与英雄介绍弹窗同款）+ 居中六边形面板（约 1020×560，`drawHexPanel`），盖在首页之上但不遮挡 HUD 层之外的任何战斗元素（只在 menu/settings 状态出现）。
- **防穿透**：遮罩上挂 `BlockInputEvents`（同 `charDetail` 做法），引导打开时点击不会穿透到下面的「开始游戏」等按钮。
- **键盘可达**：三个按钮注册 `registerKeyboardFocus`，Tab/Enter 可完成整个引导（沿用全项目键盘导航规范）。
- **宽屏适配**：面板注册进 `ScreenManager.fitToVisible()` 的处理清单，遮罩按 `visibleDesignWidth()` 铺满，全面屏无黑边。
- **平台判定**：`sys.hasFeature(sys.Feature.INPUT_TOUCH)` 决定页 3 渲染键鼠表还是触屏表（与 `TouchControls` 的设备判定同源）。

## 5. 实现方案

```
ui/TutorialUI.ts          新增。两部分：
  ├─ TutorialState        纯逻辑类（headless 可测）：页码步进/跳过/完成、
  │                       按平台取文案、引导标记读写与弹出判定（存储可注入）
  └─ TutorialUI           面板构建（同 SaveSelectUI 风格：class 接 parent Node + callbacks）
ui/ScreenManager.ts       小改：
  ├─ ScreenName 联合类型增 'tutorial'；onLoad 构建 TutorialUI 并注册 _panels
  │  （注册进 _panels 即免费获得 hideAll 关闭与键盘焦点循环）
  ├─ fitToVisible() 增 tutorial 分支
  └─ 设置页增「新手引导」按钮 + onReplayTutorial 回调
core/GameManager.ts       小改：
  ├─ onLoad 末尾（_setState('menu') 后）判定是否自动弹出（延迟 0.4s）
  └─ 接线：onTutorialFinished / onReplayTutorial（记录来源页，关闭后回去）
```

- **不动** `SaveSystem`（引导标记是设备级，不进档案，避免污染存档码导出/导入语义）。
- 存储注入复用 `AchievementAdmin` 的 `AdminStorage` 模式：无 localStorage 环境退化为内存 Map，headless 测试直接传 mock。
- 日志遵循规范：异常路径仅 `console.warn('[Tutorial] ...')`（如标记写入失败）。

## 6. 边界情况

| 情况 | 处理 |
|---|---|
| 老玩家升级 | 不弹（判定表第 2 行），静默补标记 |
| 存档码导入 | 只覆盖槽位 key，不触碰引导标记——导入者被视为已看过 |
| 删除存档槽 | 同上，不重置引导标记（重看走设置页） |
| 移动端竖屏 | `TouchControls` 的「请横屏游玩」遮罩独立于本引导；引导页设计为横版排版，竖屏下被横屏遮罩盖住属可接受（引导在首页，旋转后正常显示） |
| 引导打开时点设置页/测试房间 | 遮罩拦截触摸，不可穿透；键盘导航焦点循环锁定在引导三个按钮上 |
| 后台管理面板 | 只从设置页进入，与首次引导（首页）无叠加场景 |

- 新增 `tests/specs/tutorial.test.js`（`node:test`，全 headless）：
  - `TutorialState` 步进：next/prev 边界、跳过直达完成、末页「开始行动」触发完成回调；

- 无新 art 引用，`artmanifest.test.js` 不受影响。
- 验收命令：`npm test` 全绿；`npm run typecheck` 通过。
