# 战斗表现与碰撞修正（2026-10-09）

## 本轮反馈与根因

此前验收主要覆盖固定站位扣血与动画触发，没有充分覆盖无敌模式、移动、墙边混战。不能用此前的固定站位通过结论替代这些场景。

| 用户反馈 | 修正 |
| --- | --- |
| 断针不朝英雄打 | 移除“英雄面朝方向 × 70”的伪移动预判，锁定英雄真实位置；枪口到目标重新求方向。三发连射保留锁定点，英雄在前摇之后横移仍可躲避。酸囊同样移除朝向 × 45 的偏移。 |
| 毒射手等命中不可见 | 无敌、技能保护和受击保护帧以前在触发特效前返回，现在免伤仍显示接触；蛛后、炉城技能的上游提前返回也已修正。护盾完全吸收仍显示格挡。 |
| 命中效果容易消失 | 独立的英雄接触节点池避免被其他粒子占满；动画跟随移动英雄，400ms 生命周期，爆发帧停留160ms；同源节流，最多两种来源并存。 |
| 酸囊脚下是巨大图标、荧光几何 | 新增贴地酸液四帧动画，包含不规则边缘、少量气泡和低矮蒸气；不再把毒弹图标放大，也不再叠加荧光多边形。火区使用焦痕和余烬。 |
| 圆盘和扇面廉价 | 普通近战移除泛用圆盘；范围预警保留与判定一致的窄幅断续外缘，不填满整片地面；首领蓄力集中在武器/身体，释放仍使用各自攻击动画。机械横劈、落地、集束导弹、蛛后落点、炉城炮击/磁场、深海预警、沉默领域和折面扇区同步调整。 |
| 多种攻击像冰 | 水刺、机械追踪弹、电浆、毒刺分别补画独立动画；重盾、岩石、铆甲、龟甲重击不用泛用蓝色火花。图集加载时清除池节点旧贴图，避免异步换图串材质。持续燃烧和电浆余灼不再播放绿色毒泡。水爆、毒爆、机械落地也分别使用水花、酸液和金属碎屑，不再套通用火球圆环。 |
| 敌人走到英雄中心 | 统一实体分离，优先推开敌人，墙边侧向让位，再处理剩余挤压；延迟技能/召唤之后再收尾。死亡和升空实体不阻挡。打击停顿允许移动的独立分支同样执行地形与身体碰撞。 |

## 参考与实现取舍

查阅了 Riot 的 [Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/) 和官方 [Mid-Season Magic](https://na.leagueoflegends.com/en/featured/mid-season-magic) 中 Cassiopeia 的毒云说明。

这里采用的是“预警边缘说明范围、材质说明攻击性质、接触动画说明命中”的实现方式：毒液落地后用低矮残留，命中身体时单独飞溅；不直接复制其他游戏素材。保留必要的范围信息，避免把整个范围涂成一块高亮圆盘。
