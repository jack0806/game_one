# 军需商店与装备库 · 概念与实施

日期：2026-10-28。首版概念通过内置 image_gen 生成；用户随后选定装备库风格，要求两页统一开发。现已接入真实存档，下面保留首轮概念，并记录最终实现。

## 最终实施

商店与装备库共用 `DepotUI` 和 `DepotStyle`，大厅入口打开全屏军需终端，顶部可在两页之间直接切换。正式版以装备库的围框、切角金属面板、右侧大图详情为统一基准；商店改成左侧战备摘要与商品陈列、右侧商品详情和购买按钮。

新增正式资源：

| 资源 | 规格与用途 |
| --- | --- |
| `ui_depot_background` | 1672×941；无文字、无控件的仓库背景及左右 / 底部围框 |
| `ui_depot_items` | 1254×1254 RGBA；3×3 网格，依次为火力核心 / 强化装甲 / 瞄准镜 / 推进器 / 吸金器 / 装备箱 / 战备金库 / 战备情报 / 战备护盾 |

道具按网格切片共享纹理，完整保留透明通道，加载走 `SpriteUtils → artPath`。面板、按钮、文字、价格、属性、品质、已出战标签均由代码构建；新资源有独立 UUID，不覆盖既有 PNG。

装备库支持三格装卸、满槽明确选择替换位置、普通 / 稀有 / 史诗筛选、每页十件的仓库分页、单件详情与永久卖出二次确认。暴击率正确显示为百分比。商店沿用原价与加成，支持补给重复叠加、装备按解锁品质去重入仓，余额不足或当前可购组合集齐时禁用购买。

终端遮挡后方点击，Tab / Enter 焦点限定在当前终端，返回大厅后恢复大厅焦点范围。宽屏仅延展背景，中心控件与道具保持原比例。

## 设计方向

沿用现有选英雄页面与废土街道的粗轮廓、分块明暗和蓝灰工业材质。左右装甲立柱连接底部柜台，形成 U 形围框；青色能量灯承担交互引导，金色提示货币，品质分别以灰、蓝、紫及文字标识。环境细节集中在四周，内容区使用深蓝底板。

## 军需商店

[完整效果图](shop-v1.png)

保留大厅商店现有四种商品，使用 2×2 展柜布局，商品实体插画、说明和购买按钮分区。顶部显示核心币，底部集中展示已购且待下局生效的战备。

示例数据：核心币 1,280；装备箱 60、战备金库 25、战备情报 40、战备护盾 30 核心币。已购战备为金币 +300、连抽 +3、护盾 +60。所有数据仅存在于图中。

## 装备库

[完整效果图](armory-v1.png)

上方 3 个出战槽，下方 5×2 仓库网格，右侧单件装备大图、属性和操作。用选中描边、品质文字和已出战标签区分状态，避免逐张卡片堆放多个操作按钮。界面中的品质筛选是布局提案，尚未实现。

示例数据：仓库 10/15；出战装备为史诗火力核心（伤害 +10%）、史诗强化装甲（生命 +12%）、史诗瞄准镜（暴击率 +6%）。选中核心的卖出价 90 核心币，按当前默认史诗卖金 450 × 折算率 20% 展示。
