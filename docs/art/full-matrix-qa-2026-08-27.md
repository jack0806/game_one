# Hexblast 全矩阵美术与玩法验收（2026-08-27）

## 验收边界与原则

- 预览环境：Cocos Creator 3.8.8 Web 预览，设计分辨率 1280×720。
- 验收方式：使用 Codex 内置浏览器直接操作 Cocos 画布；技能、词条和页面不是只读源码推断。
- 视觉原则：保留“末世科技废土 + 海克斯能量”的原始设定；只增强角色辨识、攻击语义、危险预告、信息层级和移动可信度。
- 新怪暂时只进入测试房。正式章节、解锁、图鉴和掉落位置尚未由策划确定，因此本轮没有擅自接入正式流程。
