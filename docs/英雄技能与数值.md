# 英雄技能与基础数值总览

> 数据来源：`assets/scripts/data/CharacterDB.ts`（以代码为准，本文档随英雄调整同步更新）
> 通用机制：冲刺 Shift/Space（冷却 3 秒）；Q/E 按键释放（受冷却缩减影响）；R 为充能制（充能满后按 R 释放）；暴击公式 `伤害×(1+暴击伤害加成)`；护甲减伤 `armor/(armor+100)`。
